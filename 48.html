By 9:20, the payment processor has already shut off your key — from their side. They saw your key being used from a place it should never be used, and they did not wait for you to call.

The phone rings at 11:52 that same night. It is the processor's fraud desk, which does not sleep: your key is being used from a place it should never be used. They shut it off while you are still finding your shoes.

The finding fits in one sentence: the keys lived where the work happened, and this morning, the work was not yours. Now every place a file has ever been copied is a place a key may have gone. Backups. Old images. The move from March. Each one is a phone call. Some are worse.

Shutting off the key took minutes. Being sure takes three weeks — and the third week is when you learn that shutting it off was the easy part.

A true note: Keys at rest in reachable places is the best-documented failure class in this genre: a single backend misconfiguration exposed roughly 1.5 million API tokens (Wiz Research, 2026).
