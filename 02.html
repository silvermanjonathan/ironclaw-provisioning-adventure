The first question: where should Bursar's secret keys live? The keys can open the company's money accounts, so this matters.

The security guide says to use the system keyring. It is like a locked safe, but it takes time. An environment variable is faster — like hiding the key under the doormat. A plain file is easiest of all. The quickstart guide shows it that way.

Noor stops in the doorway. "Wherever you put them, that's where they stay," she says. "Nobody ever moves keys later."

If you lock the keys in the system keyring, Turn to page 3. If you use the environment variable, Turn to page 4. If you save the keys in a plain file, Turn to page 5.
