One more setting: limits on the payment routine. A speed limit. A count limit. A spending cap.

Here the two official manuals disagree. One says safe limits are already on. The other says there are no limits at all unless you set them. Setting all three takes the whole afternoon. The speed limit alone takes ten minutes. Trusting the friendly manual takes no time at all.

If you set all three limits, Turn to page 34. If you set only the speed limit, Turn to page 35. If you trust the manual that says you are already safe, Turn to page 36.
